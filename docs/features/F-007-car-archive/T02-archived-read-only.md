## Описание
Архивная машина доступна только для чтения (PRD FR-ARC-3, Допущение A7). Все изменяющие операции, которые есть
к этому моменту, отклоняются: редактирование карточки, смена статуса, оформление, исправление и отмена продажи.
Запрет затрат по архивной машине добавляется в F-008 вместе с затратами.

## Критерии приёмки
- [ ] AC-1: Given архивная машина, When владелец редактирует карточку (F-004/T02), Then ошибка «машина в архиве,
  сначала верните её из архива», атрибуты не изменены.
- [ ] AC-2: Given архивная машина в рабочем статусе, When ручная смена статуса (F-005/T02), Then та же ошибка,
  статус не изменён, в истории нет новой записи.
- [ ] AC-3: Given архивная непроданная машина, When оформление продажи, Then та же ошибка.
- [ ] AC-4: Given архивная проданная машина, When исправление данных продажи или отмена продажи, Then та же ошибка,
  данные продажи не изменены.
- [ ] AC-5: Given машину вернули из архива, When выполняются операции из AC-1..AC-4, Then они снова работают
  по своим правилам.
- [ ] AC-6: Given архивная машина пользователя A, When пользователь B выполняет любую из этих операций, Then ответ
  «не найдено» (изоляция важнее), а не «машина в архиве».
