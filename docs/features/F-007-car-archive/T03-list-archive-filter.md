## Описание
Список машин получает фильтр по архиву: «без архивных» (по умолчанию), «только архивные», «все» (PRD FR-CAR-5,
FR-ARC-2). Фильтр комбинируется со всеми остальными фильтрами и поиском. В элементе списка виден признак «в архиве».

## Критерии приёмки
- [ ] AC-1: Given у A 3 обычные и 2 архивные машины, When запрос без фильтра по архиву, Then 3 машины.
  С явным «без архивных» — те же 3.
- [ ] AC-2: Given те же машины, When «только архивные», Then 2 машины с признаком «в архиве».
- [ ] AC-3: Given те же машины, When «все», Then 5 машин, признак «в архиве» показан у двух.
- [ ] AC-4: Given «только архивные» + фильтр «Продана» + поиск `toyota`, When запрос, Then применяются все три условия.
- [ ] AC-5: Given недопустимое значение фильтра по архиву, When запрос, Then ошибка поля с перечнем допустимых значений.
- [ ] AC-6: Given архивные машины пользователя B, When A запрашивает «все» или «только архивные», Then машин B нет.
