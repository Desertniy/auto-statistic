## Описание
Владелец переносит машину в архив из любого статуса и возвращает её обратно (PRD FR-ARC-1, FR-ARC-2, FR-ARC-4,
FR-ARC-5, FR-ARC-7). Архив — признак, а не статус: статус сохраняется. Архивная машина скрыта из списка
по умолчанию, но карточка и история доступны. Отдельные фильтры по архиву — T03.

## Критерии приёмки
- [ ] AC-1: Given проданная машина, When владелец архивирует её с комментарием, Then у карточки признак «в архиве»,
  статус «Продана» сохранён, а машины нет в списке по умолчанию, в том числе при фильтрах по статусам и поиске.
- [ ] AC-2: Given машина в любом статусе («Куплена», рабочий, свой), When архивирование, Then успех.
- [ ] AC-3: Given машина уже в архиве, When повторное архивирование, Then ошибка «машина уже в архиве».
- [ ] AC-4: Given архивная машина, When запрошены карточка и история по идентификатору, Then они доступны. В истории
  запись «архивирование»: статус не меняется, инициатор «пользователь», дата и время, комментарий.
- [ ] AC-5: Given архивная машина, When владелец возвращает её из архива, Then признак снят, машина снова в списке
  по умолчанию с тем же статусом и данными. В истории запись «возврат из архива».
- [ ] AC-6: Given машина не в архиве, When возврат из архива, Then ошибка «машина не в архиве».
- [ ] AC-7 (счётчики и статусы): Given архивная машина в своём статусе «На покраске», When просмотрен справочник
  статусов, Then машина учтена в счётчике «На покраске». When пользователь удаляет этот статус, Then ошибка
  «в статусе 1 машина» (FR-UST-4).
- [ ] AC-8 (VIN): Given архивная машина с VIN X, When владелец создаёт новую машину с VIN X, Then ошибка уникальности VIN.
- [ ] AC-9 (изоляция): Given машина A, When B архивирует её или возвращает из архива, Then «не найдено», состояние
  не изменено, в журнале аудита событие отказа в доступе.
