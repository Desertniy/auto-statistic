## Описание
Сквозной набор автотестов изоляции (PRD FR-ISO-8) по всем операциям с данными MVP: машины, статусы, история,
продажа, архив, категории, затраты, сводка, аналитика. Каждая фича уже проверяла свои операции. Этот набор нужен,
чтобы ни одна существующая и ни одна будущая операция не осталась без проверки. Новая операция с данными без проверки
изоляции должна обнаруживаться автоматически (Допущение: например, тест сверяет перечень ресурсов API с перечнем
покрытых). Способ выбирает architect.

## Критерии приёмки
- [ ] AC-1: Given пользователи A и B, у A есть машина (проданная и архивная — тоже), свой статус, своя категория,
  затраты, When B выполняет каждую операцию чтения и изменения над объектами A по их идентификаторам, Then каждый ответ
  идентичен ответу для несуществующего объекта, данные A не изменены.
- [ ] AC-2: Given те же данные, When B запрашивает списки, поиск, справочники статусов и категорий, сводки и все отчёты
  аналитики, Then данных A в ответах нет, а счётчики и суммы B не включают данных A.
- [ ] AC-3: Given B пытается связать свои данные с объектами A (чужой статус для своей машины, чужая категория для
  своей затраты, фильтр по чужому статусу), When запросы, Then ошибка «не найдено» и никаких изменений.
- [ ] AC-4: Given в API добавлен новый ресурс с данными пользователя без проверки изоляции в наборе, When выполнен
  `./gradlew build`, Then сборка падает с указанием непокрытого ресурса.
- [ ] AC-5: Given операции без входа, When они вызываются, Then все ресурсы с данными отвечают «не аутентифицирован».
- [ ] AC-6: Given попытки B из AC-1, When просмотрен журнал аудита, Then есть события отказа в доступе к чужому объекту.
