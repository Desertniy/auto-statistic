# F-011: Проверка безопасности и готовность MVP к запуску

## Исходный запрос
> ...желательно сразу на хорошем уровне сделать, так как проект может зарекомендовать.
>
> Сервис для РФ, соответствие 152-ФЗ нужно.

Десятая, завершающая фича MVP по карте из [`docs/PRD.md`](../../PRD.md), раздел 12. Источник требований: PRD 6.2
(NFR-SEC-1, 2, 5, 6), FR-ISO-8, 5.7, метрики раздела 9.

## Проблема и цель
К этому моменту все функции MVP готовы, и каждая фича проверяла изоляцию и безопасность своих операций. Перед запуском
нужна сквозная проверка: единые настройки HTTP-безопасности для внешнего веб-интерфейса, регрессионный набор изоляции
по всем операциям, контроль уязвимых зависимостей и проверка по чек-листам ASVS L2 и 152-ФЗ.

**Цель:** подтвердить, что MVP соответствует PRD 6.2 и 5.7, и закрепить это автоматическими проверками.

**Признак успеха:** `./gradlew build` включает регрессионный набор изоляции и проверку зависимостей. Чек-листы ASVS L2
и 152-ФЗ заполнены, и в них нет открытых пунктов уровня blocker.

## Пользовательские сценарии
- Как владелец сервиса, я хочу быть уверен перед запуском, что ни один пользователь не видит чужие данные.
- Как владелец сервиса, я хочу видеть, какие требования ASVS L2 и 152-ФЗ выполнены, а какие остаются организационными.

## Объём
**Входит:** настройки HTTPS/HSTS, заголовков безопасности и CORS; регрессионный набор изоляции по всем операциям
с данными; проверка зависимостей на уязвимости в сборке; чек-листы ASVS L2 и 152-ФЗ с устранением найденного.

**Не входит (out of scope):** внешний пентест (не обязателен, PRD Q24); CI, Docker, развёртывание и выбор хостинга
(PRD O2); юридические тексты (O3) и уведомление Роскомнадзора (O4) — организационные задачи владельца.

## Критерии приёмки фичи
- [ ] AC-1: Given регрессионный набор изоляции, When выполнен `./gradlew build`, Then для каждой операции с данными
  подтверждено, что пользователь B не может прочитать, изменить или архивировать данные A и не видит их в списках,
  сводках и аналитике.
- [ ] AC-2: Given зависимость с известной критической уязвимостью, When выполнен `./gradlew build`, Then сборка падает
  с понятным отчётом.
- [ ] AC-3: Given чек-листы ASVS L2 и 152-ФЗ, When они просмотрены, Then по каждому пункту есть статус и ссылка
  на подтверждение, открытых пунктов уровня blocker нет.

## Нефункциональные требования
- Проверки не должны заметно замедлять локальную сборку (ориентир — до +2 минут к `./gradlew build`, Допущение).
