## Описание
Финальная проверка MVP по OWASP ASVS L2 (PRD NFR-SEC-1, подтверждено Q24) и по требованиям 152-ФЗ из PRD 5.7.
Охватываются применимые разделы: аутентификация, сессии, контроль доступа, валидация, ошибки и логирование, хранение
секретов, защита данных. Результат — заполненные чек-листы в документации проекта. Найденные несоответствия либо
устраняются в рамках задачи, либо оформляются отдельными задачами с указанием уровня. Организационные пункты (хостинг
в РФ, юридические тексты, уведомление Роскомнадзора) отмечаются как зависящие от владельца (PRD O2–O4) и сборку
не блокируют.

## Критерии приёмки
- [ ] AC-1: Given чек-лист ASVS L2, When он просмотрен, Then по каждому применимому требованию есть статус («выполнено»,
  «не применимо» с причиной, «не выполнено» с уровнем) и ссылка на подтверждение: тест, задача или настройка.
- [ ] AC-2: Given чек-лист 152-ФЗ по PRD FR-PD-1..7, When он просмотрен, Then по каждому пункту есть статус
  и подтверждение. Пункты, зависящие от владельца (хостинг в РФ, тексты, Роскомнадзор, контакт оператора), помечены
  «организационный, отложено пользователем / вне разработки».
- [ ] AC-3: Given найдены несоответствия уровня blocker, When задача завершается, Then все они устранены и подтверждены
  тестами. Пункты уровня major и ниже либо устранены, либо оформлены отдельными задачами со ссылкой из чек-листа.
- [ ] AC-4: Given сквозной сценарий MVP из PRD раздел 9: регистрация с согласием → подтверждение → вход → машина →
  статусы → затраты → продажа → отмена → повторная продажа → архив → сводка → аналитика → выход, When выполнен
  автотест, Then все шаги успешны, а журнал аудита содержит события безопасности сценария без секретов.
- [ ] AC-5: Given журналы и логи после сквозного сценария, When они проверены на секреты, Then паролей, токенов
  и ссылок с токенами нет.
