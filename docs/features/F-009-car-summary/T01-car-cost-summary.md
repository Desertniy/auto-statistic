## Описание
Сводка по машине (PRD FR-SUM-1, FR-SUM-2, FR-SUM-4, FR-SUM-5): цена покупки, затраты по категориям, итого затрат,
себестоимость и срок владения в днях. Продажа и прибыль — T02. Сводка доступна и для архивной машины.

## Критерии приёмки
- [ ] AC-1: Given машина: покупка 500 000,00, затраты «Ремонт» 30 000,00 и 15 000,00, «Реклама» 2 000,00, When запрошена
  сводка, Then цена покупки 500 000,00, затраты по категориям: «Ремонт» 45 000,00, затем «Реклама» 2 000,00 (по убыванию
  суммы), итого затрат 47 000,00, себестоимость 547 000,00.
- [ ] AC-2: Given категория без затрат, When сводка, Then этой категории в разбивке нет.
- [ ] AC-3: Given машина без затрат, When сводка, Then разбивка пуста, итого 0,00, себестоимость равна цене покупки.
- [ ] AC-4 (точность): Given затраты 0,10 + 0,20 и 33 333,33 × 3, When сводка, Then итог ровно 100 000,29, без ошибок
  округления.
- [ ] AC-5 (срок владения): Given непроданная машина куплена 10 дней назад, When сводка, Then срок владения 10 дней.
  Машина, купленная сегодня, — 0 дней. «Сегодня» — по московскому времени, в тестах время управляемо.
- [ ] AC-6: Given затраты с датой раньше даты покупки, When сводка, Then они учитываются в себестоимости.
- [ ] AC-7: Given у двух категорий одинаковая сумма, When сводка, Then порядок между ними стабилен, по названию (Допущение).
- [ ] AC-8: Given архивная машина, When сводка, Then возвращается так же, как для обычной.
- [ ] AC-9 (изоляция): Given машина A, When B запрашивает сводку, Then «не найдено», как для несуществующей машины.
