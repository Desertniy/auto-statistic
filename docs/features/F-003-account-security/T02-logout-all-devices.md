## Описание
Если пользователь подозревает, что кто-то получил доступ к аккаунту, он завершает все свои сессии одним действием,
включая текущую (PRD FR-AUTH-9). Этот же механизм отзыва всех сессий понадобится при смене и восстановлении пароля
(T03, T04).

## Критерии приёмки
- [ ] AC-1: Given пользователь вошёл на трёх устройствах, When на одном выбирает «выйти со всех устройств», Then все
  три сессии сразу недействительны: запросы с ними и попытки продления дают «не аутентифицирован».
- [ ] AC-2: Given после этого пользователь входит заново, When он пользуется новой сессией, Then она работает.
- [ ] AC-3: Given пользователи A и B вошли, When A выходит со всех устройств, Then сессии B не затронуты.
- [ ] AC-4: Given запрос «выйти со всех устройств» без действующей сессии, When он отправлен, Then ответ «не аутентифицирован».
- [ ] AC-5: Given выход со всех устройств, When просмотрен журнал аудита, Then есть событие с числом завершённых сессий.
