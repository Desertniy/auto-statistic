## Исходный запрос
> В MVP переносится аналитика по всему бизнесу: прибыль за период (по месяцам, по проданным машинам), деньги
> в обороте (вложено в непроданные машины), затраты по категориям за период по всем машинам.

Девятая фича MVP по карте из [`docs/PRD.md`](../../PRD.md), раздел 12. Источник требований: PRD 5.4.2 (FR-AN-1..7),
FR-ARC-6, FR-ST-13, FR-ISO-4.

## Проблема и цель
Сводка по одной машине не отвечает на вопросы «сколько я заработал за месяц», «сколько денег сейчас в машинах»
и «на что уходит больше всего».

**Цель:** три отчёта по своим данным, включая архивные машины: деньги в обороте, прибыль по месяцам за период
со списком продаж, затраты по категориям за период.

**Признак успеха:** пример FR-AN-7 даёт точные значения, в том числе после отмены продажи.

## Пользовательские сценарии
- Как перекуп, я хочу видеть, сколько денег сейчас вложено в непроданные машины.
- Как перекуп, я хочу видеть прибыль по месяцам за выбранный период и какие машины её дали.
- Как перекуп, я хочу видеть, на какие категории за период ушло больше всего.

## Объём
**Входит:** деньги в обороте с разбивкой по статусам; прибыль по месяцам за период со списком продаж; затраты
по категориям за период; учёт архивных машин; исключение отменённых продаж; изоляция.

**Не входит (out of scope):** «залежавшиеся» машины, время в статусах, средний срок продажи, рентабельность,
суммы в списке машин — после MVP (PRD roadmap). Экспорт отчётов — после MVP.

## Критерии приёмки фичи
- [ ] AC-1: Given данные примера FR-AN-7 (машины A, B, C), When запрошена прибыль за 2026-01-01..2026-03-31, Then
  январь и февраль — 0 продаж, март — 2 продажи, выручка 910 000,00, себестоимость 867 000,00, прибыль 43 000,00.
- [ ] AC-2: Given те же данные, When запрошены деньги в обороте, Then 1 машина, 425 000,00.
- [ ] AC-3: Given у машины A отменена продажа, When отчёты запрошены снова, Then март — 1 продажа, выручка 310 000,00,
  прибыль −10 000,00. Деньги в обороте — 2 машины, 972 000,00.
- [ ] AC-4: Given данные пользователя B, When A запрашивает любой отчёт, Then данные B не учтены.

## Нефункциональные требования
- Отчёт за 5 лет при ~1 000 машин и ~50 000 затрат — до 1 с (NFR-4). Способ расчёта выбирает architect (QA7).
- Месяцы и «сегодня» — по московскому времени (NFR-2). Точность до копейки (NFR-1).
