## Описание
Владелец исправляет атрибуты своей машины (PRD FR-CAR-3). Правила те же, что при создании (T01). Статус, владелец
и данные продажи так не меняются.

## Критерии приёмки
- [ ] AC-1: Given машина A, When A меняет пробег, госномер и заметки, Then изменения сохранены и видны в карточке,
  остальные атрибуты не изменились.
- [ ] AC-2: Given изменение нарушает правило атрибута (как AC-3, AC-4, AC-6 в T01), When сохранение, Then ошибка
  с указанием поля, карточка не изменилась целиком: частичного сохранения нет.
- [ ] AC-3: Given у A есть машины X и Y, When A ставит машине Y VIN машины X, Then ошибка уникальности. Given A
  сохраняет машине X её собственный VIN без изменений, Then ошибки нет.
- [ ] AC-4: Given запрос пытается изменить статус или владельца, When сохранение, Then эти поля не меняются
  (игнорируются или отклоняются, выбор за architect).
- [ ] AC-5 (изоляция): Given машина A, When B пытается её отредактировать, Then «не найдено», как для несуществующей,
  машина не изменена, а в журнале аудита есть событие отказа в доступе.
- [ ] AC-6: Given несуществующий идентификатор, When редактирование, Then «не найдено».
