## Описание
Список машин текущего пользователя с текстовым поиском и сортировкой по умолчанию (PRD FR-CAR-5, FR-ISO-4).
Фильтры по статусам, «только непроданные» и по архиву добавляются в F-005/T05, F-006/T04 и F-007/T03. Постраничность —
на усмотрение architect, исходя из NFR-4. Если её введут, критерии ниже должны выполняться и с ней.

## Критерии приёмки
- [ ] AC-1: Given у A три машины с датами покупки 01.03, 15.03 и 10.02, When A запрашивает список, Then все три,
  в порядке 15.03, 01.03, 10.02 (новые сверху). Для одинаковых дат порядок стабилен между запросами.
- [ ] AC-2: Given у A машины «Toyota Camry» (VIN `XTA21099071234567`, госномер `А123ВС777`) и «Kia Rio», When поиск
  `camr`, `toyota`, `1234567` или `а123`, Then найдена только Camry: подстрока ищется без учёта регистра по марке,
  модели, VIN и госномеру.
- [ ] AC-3: Given поиск без совпадений, When запрос, Then пустой список, а не ошибка.
- [ ] AC-4: Given пустая строка поиска или строка из пробелов, When запрос, Then поведение как без поиска (Допущение).
- [ ] AC-5 (изоляция): Given у B есть машина «Toyota Camry», When A ищет `toyota`, Then машины B в выдаче нет.
  Given у пользователя нет машин, When он запрашивает список, Then пустой список.
- [ ] AC-6: Given элемент списка, When он просмотрен, Then в нём есть идентификатор, марка, модель, год, VIN, госномер,
  статус, дата и цена покупки (Допущение по составу полей).
- [ ] AC-7 (производительность): Given у пользователя 1 000 машин, When запрос списка с поиском, Then ответ до 1 с
  в тестовом окружении (NFR-4).
