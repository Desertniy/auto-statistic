## Описание
Владелец отменяет продажу, и машина возвращается в работу (PRD 5.2.3, подтверждено Q4). Детали — допущения PRD
A2–A4: машина возвращается в статус перед продажей, а если тот свой статус удалён — в «На продаже». Цена и дата
продажи очищаются и сохраняются в записи истории. Инициатор — пользователь. После отмены машину можно продать снова.

## Критерии приёмки
- [ ] AC-1: Given машина была в «Забронирована» и продана за 600 000,00 датой 10.03, When продажа отменена
  с комментарием «покупатель вернул», Then статус «Забронирована», цена и дата продажи в карточке пусты.
- [ ] AC-2: Given отмена из AC-1, When запрошена история, Then последняя запись: тип «отмена продажи», предыдущий
  статус «Продана», новый «Забронирована», инициатор «пользователь», отменённые цена 600 000,00 и дата 10.03,
  комментарий. Запись «продажа» осталась.
- [ ] AC-3: Given машину продали из «Куплена», When продажа отменена, Then статус «Куплена» (системный статус
  восстанавливается системой, не вручную).
- [ ] AC-4: Given машину продали из своего статуса «На покраске», а затем этот статус удалили, When продажа
  отменена, Then статус «На продаже».
- [ ] AC-5: Given машину продали, исправили цену на 590 000,00 (T02), When продажа отменена, Then в записи отмены
  цена 590 000,00, то есть действовавшая на момент отмены.
- [ ] AC-6: Given после отмены, When продажа оформлена снова за 610 000,00, затем снова отменена, Then всё успешно.
  В истории две пары «продажа» и «отмена продажи», число отмен не ограничено.
- [ ] AC-7: Given машина не продана, When отмена продажи, Then ошибка «машина не продана», ничего не изменено.
- [ ] AC-8: Given отменённая продажа, When просмотрены счётчики справочника статусов, Then машина учитывается
  в статусе, в который вернулась, а не в «Продана».
- [ ] AC-9 (изоляция): Given проданная машина A, When B отменяет продажу, Then «не найдено», машина не изменена.
