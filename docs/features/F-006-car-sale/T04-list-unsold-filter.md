## Описание
Список машин получает фильтр «только непроданные»: все статусы, кроме «Продана» (PRD FR-CAR-5). Фильтр
комбинируется с фильтром по статусам и с поиском.

## Критерии приёмки
- [ ] AC-1: Given у A машины в «Куплена», «На продаже» и две в «Продана», When фильтр «только непроданные», Then
  две непроданные машины.
- [ ] AC-2: Given машина после отмены продажи, When фильтр «только непроданные», Then она в выдаче.
- [ ] AC-3: Given «только непроданные» + фильтр по статусу «На продаже», When запрос, Then только машины в «На продаже».
- [ ] AC-4: Given «только непроданные» + фильтр по статусу «Продана», When запрос, Then пустой список. Противоречивое
  сочетание не считается ошибкой (Допущение).
- [ ] AC-5: Given «только непроданные» + поиск, When запрос, Then применяются оба условия. Машин других пользователей
  в выдаче нет.
