## Описание
Владелец проданной машины исправляет цену и/или дату продажи по тем же правилам, что при оформлении. Статус
не меняется, отдельной записи в истории нет (PRD FR-ST-6, FR-HIST-4, Допущение A4).

## Критерии приёмки
- [ ] AC-1: Given машина продана за 600 000,00, When цена исправлена на 590 000,00, Then в карточке 590 000,00,
  статус «Продана», дата продажи прежняя.
- [ ] AC-2: Given проданная машина, When исправлена только дата (в пределах правил), Then дата обновлена, цена прежняя.
- [ ] AC-3: Given исправление нарушает правила (цена 0 или с тремя знаками, дата раньше покупки или в будущем), When
  запрос, Then ошибка поля, данные продажи не изменены.
- [ ] AC-4: Given машина не продана, When исправление данных продажи, Then ошибка «машина не продана».
- [ ] AC-5: Given исправление выполнено, When запрошена история, Then новой записи нет, а запись «продажа» хранит
  исходные значения (Допущение: история — это журнал событий, исправление событием не считается).
- [ ] AC-6 (изоляция): Given проданная машина A, When B исправляет данные продажи, Then «не найдено», данные не изменены.
