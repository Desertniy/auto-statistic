## Описание
Владелец добавляет затраты по своей машине и смотрит их список с итогом (PRD FR-EXP-1..4). Затраты разрешены
в любом статусе, включая проданную машину (подтверждено, Q12), но не у архивной (FR-ARC-3). Дата затраты не позже
сегодняшней и может быть раньше даты покупки (Допущение A13). Будущие даты не принимаются (подтверждено, Q11).
С этой задачи своя категория с затратами не удаляется (FR-CAT-3).

## Критерии приёмки
- [ ] AC-1: Given машина A, When добавлена затрата: категория «Ремонт», сумма 30 000,00, дата — вчера, комментарий
  «замена ГРМ», Then затрата создана с идентификатором, и ответ содержит все поля.
- [ ] AC-2: Given затраты 30 000,00 (05.03), 15 000,00 (07.03), 2 000,00 (06.03), When запрошен список затрат машины,
  Then три записи в порядке 07.03, 06.03, 05.03 (новые сверху), итог 47 000,00 без ошибок округления.
- [ ] AC-3 (сумма): Given сумма 0, отрицательная, с тремя знаками после запятой или 100 000 000,01, When добавление,
  Then ошибка поля. 0,01 и 100 000 000,00 принимаются.
- [ ] AC-4 (дата): Given дата завтрашняя, When добавление, Then ошибка поля. Сегодняшняя дата и дата раньше даты
  покупки принимаются. Без даты — ошибка.
- [ ] AC-5 (категория и комментарий): Given без категории, с несуществующей или чужой категорией (B), When добавление,
  Then ошибка «категория не найдена», одинаковая для несуществующей и чужой. Комментарий из 1001 символа — ошибка,
  без комментария — успех. Своя категория A работает.
- [ ] AC-6 (статусы машины): Given машина в «Продана», When добавлена затрата, Then успех. Given архивная машина,
  When добавление, Then ошибка «машина в архиве», а список её затрат доступен.
- [ ] AC-7 (удаление категории): Given у своей категории есть затрата, в том числе у архивной машины, When категорию
  удаляют, Then ошибка «в категории есть затраты».
- [ ] AC-8 (изоляция): Given машина A, When B добавляет затрату к ней или запрашивает список её затрат, Then «не найдено»,
  как для несуществующей машины, в журнале аудита событие отказа в доступе.
- [ ] AC-9: Given машина без затрат, When запрошен список, Then пустой список и итог 0,00.
