## Описание
Справочник категорий (PRD FR-CAT-1..3, подтверждено Q5). Девять предустановленных категорий общие для всех
и неизменяемы. Свои категории пользователь создаёт, переименовывает и удаляет (только без затрат). Видны они только
ему. Правило «нельзя удалить категорию с затратами» начинает проверяться, когда появятся затраты (T02). В этой
задаче своя категория без затрат удаляется.

## Критерии приёмки
- [ ] AC-1: Given новый пользователь, When запрашивает справочник, Then ровно 9 предустановленных категорий: «Ремонт»,
  «Запчасти», «Подготовка и детейлинг», «Документы и оформление», «Транспортировка», «Реклама», «Стоянка и хранение»,
  «Топливо», «Прочее». У каждой есть идентификатор, название и вид «предустановленная».
- [ ] AC-2: Given пользователь A, When создаёт категорию «  Комиссия площадки  », Then создана «Комиссия площадки» вида
  «своя». Она в справочнике A после предустановленных, свои — в порядке создания (Допущение).
- [ ] AC-3 (название): Given пустое, из пробелов или длиннее 50 символов, When создание или переименование, Then ошибка
  поля. 50 символов принимаются.
- [ ] AC-4 (уникальность): Given у A есть «Комиссия площадки», When A создаёт «комиссия ПЛОЩАДКИ» или «ремонт», Then
  ошибка «категория с таким названием уже есть». Given B создаёт «Комиссия площадки», Then успех.
- [ ] AC-5 (переименование): Given своя категория, When A переименовывает её в свободное название, Then название
  обновлено. Переименование в название другой доступной категории — ошибка уникальности.
- [ ] AC-6 (удаление): Given своя категория без затрат, When A удаляет её, Then она пропала из справочника.
- [ ] AC-7 (предустановленные): Given предустановленная категория, When переименование или удаление, Then ошибка
  «категорию нельзя изменить».
- [ ] AC-8 (изоляция): Given своя категория A, When B запрашивает справочник, переименовывает или удаляет её по
  идентификатору, Then категории A у B не видно, а операции дают «не найдено».
