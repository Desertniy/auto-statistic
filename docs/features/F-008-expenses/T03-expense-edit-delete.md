## Описание
Владелец исправляет или удаляет затрату своей машины (PRD FR-EXP-2). Правила полей — как при добавлении (T02).
Перенос затраты на другую машину не предусмотрен (Допущение). Затраты архивной машины не меняются (FR-ARC-3).

## Критерии приёмки
- [ ] AC-1: Given затрата 30 000,00 «Ремонт», When сумма исправлена на 32 500,00, а категория на «Запчасти», Then
  изменения сохранены, итог списка затрат пересчитан.
- [ ] AC-2: Given исправление нарушает правила (сумма, дата, категория, комментарий — как AC-3..AC-5 в T02), When
  сохранение, Then ошибка поля, затрата не изменена целиком.
- [ ] AC-3: Given затрата, When владелец её удаляет, Then её нет в списке, итог уменьшился на её сумму.
  Повторное удаление — «не найдено».
- [ ] AC-4: Given своя категория, у которой была единственная затрата, When затрату удалили, Then категорию можно удалить.
- [ ] AC-5 (архив): Given затрата архивной машины, When редактирование или удаление, Then ошибка «машина в архиве»,
  затрата не изменена. После возврата машины из архива операции работают.
- [ ] AC-6 (изоляция): Given затрата A, When B редактирует или удаляет её по идентификатору, Then «не найдено»,
  затрата не изменена, в журнале аудита событие отказа в доступе.
- [ ] AC-7: Given запрос пытается перенести затрату на другую машину, When сохранение, Then машина затраты
  не меняется (поле игнорируется или отклоняется, выбор за architect).
