## Описание
Владелец машины вручную ставит ей рабочий статус. Переходы свободные (PRD FR-ST-1, FR-ST-2, FR-ST-4, FR-ST-7,
подтверждено Q14). Системные статусы вручную не ставятся, возврата в «Куплена» нет (Q15). К смене можно приложить
комментарий. Запись в историю — T04.

## Критерии приёмки
- [ ] AC-1: Given машина в «Куплена», When владелец ставит «В ремонте» с комментарием «замена ГРМ», Then статус
  «В ремонте», и карточка, список и счётчики справочника это отражают.
- [ ] AC-2: Given машина в «В ремонте», When владелец ставит «На продаже», затем «Забронирована», затем снова
  «В ремонте», Then все переходы успешны: порядок рабочих статусов не ограничен.
- [ ] AC-3: Given любая машина, When владелец ставит «Куплена» или «Продана», Then ошибка «системный статус
  ставится автоматически», статус не изменён.
- [ ] AC-4: Given машина в «На продаже», When владелец ставит «На продаже», Then ошибка «машина уже в этом статусе».
- [ ] AC-5: Given несуществующий идентификатор статуса, When смена, Then ошибка «статус не найден», статус не изменён.
- [ ] AC-6: Given комментарий из 501 символа, When смена, Then ошибка поля. 500 символов и пустой комментарий принимаются.
- [ ] AC-7 (изоляция): Given машина A, When B пытается сменить ей статус, Then «не найдено», статус не изменён,
  в журнале аудита есть событие отказа в доступе.
