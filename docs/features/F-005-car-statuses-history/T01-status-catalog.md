## Описание
Справочник статусов, общий для всех пользователей (PRD 5.2.1, FR-UST-1, FR-UST-6): системные «Куплена» и «Продана»,
рабочие предустановленные «В ремонте», «На продаже», «Забронирована». Пользователь получает список доступных ему
статусов с видом и числом своих машин в каждом. Свои статусы добавляются в T03 и тоже появляются в этом списке.
Машины, созданные в F-004, находятся в статусе «Куплена».

## Критерии приёмки
- [ ] AC-1: Given новый пользователь, When запрашивает справочник, Then ровно 5 статусов в порядке «Куплена»,
  «В ремонте», «На продаже», «Забронирована», «Продана». У каждого есть идентификатор, название, вид («системный»
  или «рабочий предустановленный») и число машин 0.
- [ ] AC-2: Given у A три машины, у B одна, When A запрашивает справочник, Then у «Куплена» число машин 3,
  машины B не учтены.
- [ ] AC-3: Given карточка и элемент списка машины, When просмотрены, Then статус показан названием и идентификатором
  из справочника.
- [ ] AC-4: Given любой предустановленный или системный статус, When пользователь пытается переименовать или удалить
  его, Then ошибка «статус нельзя изменить», справочник не изменился. Если операции для таких статусов вообще
  не предусмотрены, ответ тоже однозначно отказывает.
- [ ] AC-5: Given запрос без входа, When запрошен справочник, Then «не аутентифицирован».
