## Описание
У каждой машины есть история событий (PRD 5.2.5). В этой задаче в неё пишутся создание машины и ручная смена
статуса. События продажи, отмены продажи и архива добавят F-006 и F-007. Названия своих статусов в истории
следуют их переименованию. Удалённый статус показывается под последним названием с пометкой «удалён» (FR-UST-5).

## Критерии приёмки
- [ ] AC-1: Given создана новая машина, When запрошена её история, Then одна запись: тип «создание», предыдущего
  статуса нет, новый — «Куплена», инициатор «система», дата и время создания.
- [ ] AC-2: Given машина прошла «В ремонте» (комментарий «замена ГРМ»), затем «На продаже», When запрошена история,
  Then 3 записи в хронологическом порядке. У записей смены статуса есть тип «смена статуса», предыдущий и новый
  статус, инициатор «пользователь», дата и время, комментарий (если был).
- [ ] AC-3: Given машины, созданные до этой задачи (в F-004), When запрошена их история, Then первая запись
  «создание / Куплена» с датой и временем создания машины (Допущение: данные заполняются при обновлении).
- [ ] AC-4: Given в истории есть свой статус «На покраске», When его переименовали в «Покраска кузова», Then история
  показывает новое название.
- [ ] AC-5: Given в истории есть свой статус, When машину перевели из него и статус удалили, Then записи истории
  остались и показывают последнее название статуса с пометкой «удалён».
- [ ] AC-6: Given отклонённая смена статуса (например, ручная постановка «Продана»), When запрошена история, Then
  новой записи нет.
- [ ] AC-7 (изоляция): Given машина A, When B запрашивает её историю, Then «не найдено», как для несуществующей машины.
