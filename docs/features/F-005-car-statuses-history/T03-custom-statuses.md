## Описание
Пользователь создаёт рабочие статусы под свой процесс, переименовывает и удаляет их (PRD FR-UST-1..5,
подтверждено Q16, Q17). Свои статусы видны только автору и назначаются его машинам так же, как предустановленные (T02).

## Критерии приёмки
- [ ] AC-1: Given пользователь A, When он создаёт статус «  На покраске  », Then создан статус «На покраске» вида
  «пользовательский». В справочнике он стоит после «Забронирована» и перед «Продана», свои статусы идут в порядке
  создания.
- [ ] AC-2: Given свой статус, When A ставит его своей машине (T02), Then успех, счётчик статуса 1.
- [ ] AC-3 (название): Given пустое название, название из пробелов или длиннее 50 символов, When создание
  или переименование, Then ошибка поля. 50 символов принимаются.
- [ ] AC-4 (уникальность): Given у A есть «На покраске», When A создаёт «на ПОКРАСКЕ», «продана» или «В ремонте»,
  Then ошибка «статус с таким названием уже есть». Given B создаёт «На покраске», Then успех.
- [ ] AC-5 (переименование): Given машина A в статусе «На покраске», When A переименовывает его в «Покраска кузова»,
  Then карточка и список машины показывают новое название. Переименование в название другого доступного статуса
  без учёта регистра — ошибка уникальности. Переименование в то же название с другим регистром разрешено (Допущение).
- [ ] AC-6 (удаление с машинами): Given в своём статусе 2 машины, When A удаляет его, Then ошибка «в статусе
  2 машины, переведите их в другой статус», статус не удалён.
- [ ] AC-7 (удаление без машин): Given в своём статусе нет машин, When A удаляет его, Then статус пропал
  из справочника, и назначить его нельзя («статус не найден»).
- [ ] AC-8 (изоляция): Given свой статус A, When B видит справочник, пытается назначить этот статус своей машине,
  переименовать или удалить его, Then статуса A в справочнике B нет, а все операции дают «не найдено»
  (как для несуществующего статуса).
- [ ] AC-9: Given системный или предустановленный статус, When переименование или удаление, Then ошибка «статус нельзя
  изменить» (FR-UST-6).
