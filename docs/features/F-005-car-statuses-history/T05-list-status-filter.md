## Описание
Список машин из F-004/T03 получает фильтр по одному или нескольким статусам: системным, предустановленным и своим
(PRD FR-CAR-5). Фильтр комбинируется с поиском.

## Критерии приёмки
- [ ] AC-1: Given у A машины в «Куплена», «В ремонте», «На продаже» и своём «На покраске», When фильтр «В ремонте»,
  Then только машина в «В ремонте».
- [ ] AC-2: Given те же машины, When фильтр «В ремонте» + «На покраске», Then обе эти машины и только они.
- [ ] AC-3: Given фильтр по статусу и поиск `toyota`, When запрос, Then только машины, подходящие под оба условия.
- [ ] AC-4: Given фильтр по статусу, в котором нет машин, When запрос, Then пустой список.
- [ ] AC-5: Given фильтр по несуществующему или чужому (пользователя B) статусу, When запрос, Then ошибка «статус
  не найден», одинаковая в обоих случаях.
- [ ] AC-6: Given без фильтра, When запрос, Then машины во всех статусах, как в F-004/T03.
