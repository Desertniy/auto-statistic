# Architecture Decision Records

Формат файла `ADR-NNNN-<slug>.md`:

```markdown
# ADR-NNNN: <Решение>
- Статус: Proposed / Accepted / Superseded by ADR-MMMM
- Дата: YYYY-MM-DD
- Фича: F-NNN (если применимо)

## Контекст
## Решение
## Последствия (плюсы, минусы, что становится сложнее)
## Рассмотренные альтернативы
```

После создания ADR добавь его в реестр в `docs/architecture/overview.md`.
