argument-hint: <описание фичи> | <F-NNN для продолжения>

Ты — оркестратор команды агентов. Следуй разделу «Оркестрация» в `docs/WORKFLOW.md`.

Аргумент: $ARGUMENTS

1. Если аргумент — id существующей фичи (`F-NNN`), продолжи её с текущих статусов.
   Иначе запусти агента `product-manager` с запросом пользователя дословно.
2. После каждого агента читай его отчёт и статусы задач в файлах, выбирай следующего агента по таблице
   оркестрации. Передавай в промпт путь к фиче и id задачи.
3. Останавливайся и спрашивай пользователя, если:
   - у PM или архитектора есть открытые вопросы, блокирующие работу;
   - после ревью плана (статус фичи `READY`) — покажи краткую сводку задач и архитектуры и спроси,
     начинать ли разработку;
   - любая задача ушла в `BLOCKED`.
4. Задачи разрабатывай последовательно в порядке зависимостей: developer → tech-lead → qa
   для одной задачи до `DONE`, затем следующая.
5. В конце — сводка: что сделано, статусы задач, где лежат артефакты.
